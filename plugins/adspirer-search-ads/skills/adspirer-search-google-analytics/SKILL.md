# Google Analytics

Load adspirer-search-mcp. Discover google_analytics with action=list_tools before execute.
Use the exact discovered tool_name and arguments. Select the correct property explicitly
when multiple properties exist; preserve returned identifiers and resource formats.
Confirm dates, timezone, currency, event definitions, and dimensions/metrics compatibility.
Use available acquisition, landing-page, engagement, and event reports to answer the question.
Separate users, sessions, events, and conversions; do not sum incompatible metrics.
Explain attribution and reporting lag when comparing GA4 with ad-platform reports.
Report sampling/thresholds or missing data if indicated. Never invent data to fill gaps.
Start read-only. Any configuration or event-definition change needs specific approval.
