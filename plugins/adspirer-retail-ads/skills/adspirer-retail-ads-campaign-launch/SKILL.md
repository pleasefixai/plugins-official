# Campaign build

Load adspirer-retail-ads-tools and the relevant platform skill.
Clarify product selection, marketplace, objective, margin/ACoS target, available inventory, total/daily budget and currency, dates, brand rights and assets.
Read existing campaigns and product eligibility/catalog state to avoid duplicates and advertising unavailable products.
Choose campaign format from live supported operations; Walmart's broad router description is not evidence of generic SB/SV creation.
Present product IDs, targeting, keywords/negatives, bids, placement adjustments, budget implications and asset requirements.
Obtain explicit approval before any creation. Amazon state PAUSED; Walmart status paused. Stop if paused creation cannot be established.
For Amazon combined builders, inspect returned children before adding anything. For Walmart, build the required hierarchy step by step.
Read back the campaign and its intended child ads/items/targets, budget and status. Report partial IDs and failures; inspect state before retrying uncertain writes.
Creating, submitting for moderation, approval and enabling are separate states. Never enable automatically.
