# Select opportunities

Propose at most **8** opportunities, ranked as an **ordered list** (`1.`, `2.`, …, most valuable first — not bullets), in `knock-plan.md` only — not in chat. If the user ever asks to see the recommendations in chat, keep the same ordered numbering.

## Priority

1. **Activation / time-to-value** — users who signed up but never completed the aha action
2. **Revenue protection** — failed payment, trial end with incomplete setup, limit hit
3. **Core loop** — collaboration that needs a response; digests for high volume
4. **Expansion** — invite teammates after first success; upgrade when hitting a gate
5. **Win-back** — only with precise state + owner, not generic inactivity

## Filter out

- Pure marketing blasts with no product state
- Duplicate of an existing well-structured transactional send
- Messages with no clear recipient action or stop condition

## Channel leanings (plan only)

| Situation | Lean toward |
| --- | --- |
| User is in-product / empty state | Guide or in-app |
| User is away / email known | Email workflow |
| Urgent ops | Push/SMS only if already used in product |
| Team ops | Slack/Teams if present in stack |
